1. Reactive System Data Flow

Input Layer

Telemetry Ingestion

Loads curated presets or synthetic simulation packets (AQI, PM2.5, PM10, NO2, O3, CO) from data.js.

Intelligence Layer

Vulnerability Engine

Evaluates particulate thresholds against active persona profile (Asthma, Athlete, Caregiver, Commuter) in app.js.

Action Layer

Mitigation Advisor

Calculates route exposure deltas (-38% particulate load) and window ventilation intervals based on ambient air severity.

Display Layer

Atmospheric UI

Dynamically shifts ambient page gradients and SVG radial stroke offsets in styles.css.

2. Codebase Structure & Tour

File Key Functions & Responsibilities
data.js Environmental benchmark presets (SF, NYC, London, Delhi, Tokyo), WHO clinical guidelines, 4 vulnerability personas, and 3 simulation scenarios.
app.js applyTelemetry(), renderHeroGauge(), renderHealthAdvisories(), renderRouteAdvisor(), and simulation event dispatcher.
styles.css Atmospheric theme variables (theme-good, theme-moderate, theme-hazardous), glassmorphism, and radial SVG progress stroke animation.
index.html Semantic responsive DOM structure with radial AQI dial, profile selector, health advisory card, pollutant breakdown, and simulation studio.
